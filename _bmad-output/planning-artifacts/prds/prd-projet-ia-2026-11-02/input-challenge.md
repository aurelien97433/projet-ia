# Entrée — Challenge NexaMind AI (fourni par l'utilisateur le 2026-11-02)

Une jeune entreprise en pleine croissance, NexaWorks, accompagne des indépendants, des petites entreprises et des équipes projet dans la gestion de leurs activités quotidiennes.

Au fil du temps, l'entreprise a accumulé une grande quantité d'informations : documents internes, notes de réunion, FAQ, procédures, fiches projets, comptes rendus clients, historiques de tâches et ressources métier.

Le problème est devenu critique : les collaborateurs perdent trop de temps à rechercher l'information, les réponses ne sont pas homogènes, et certaines connaissances importantes restent inexploitées. Les nouveaux arrivants ont également du mal à monter rapidement en compétence.

Pour répondre à cette problématique, NexaWorks souhaite lancer NexaMind AI, une application web fullstack capable de :

- centraliser les informations utiles de l'entreprise
- permettre aux utilisateurs de retrouver rapidement des ressources
- proposer un assistant conversationnel intelligent
- exploiter une base vectorielle pour interroger les contenus de manière contextuelle
- offrir une expérience moderne, fluide et sécurisée

L'objectif est de créer un véritable copilote métier intelligent, capable non seulement d'afficher des données, mais aussi de comprendre les besoins de l'utilisateur, retrouver les bonnes informations et produire des réponses utiles grâce à l'IA.

## Mission des étudiants

Intervenir comme product builders en mode Vibe Coding pour imaginer, concevoir et réaliser un MVP fonctionnel de NexaMind AI. Posture de concepteur-orchestrateur : transformer un besoin métier en produit numérique, structurer les fonctionnalités, utiliser l'IA pour accélérer conception et réalisation, assembler les briques techniques, tester/corriger/améliorer, produire une application cohérente, exploitable et crédible.

## Logique : Vibe Coding, pas codage traditionnel

Stacks possibles : Lovable + Supabase + IA + base vectorielle ; Next.js + Supabase + IA + vector store ; Symfony + IA + RAG ; ou toute stack cohérente. Démontrer : cadrer un besoin, choisir une approche technique adaptée, utiliser l'IA comme levier de production, intégrer RAG et base vectorielle, superviser la qualité fonctionnelle, améliorer par itérations.

## Fonctionnalités attendues

Un utilisateur authentifié peut :
- créer un compte et se connecter de manière sécurisée
- accéder à un tableau de bord
- ajouter, organiser ou consulter des contenus
- effectuer des recherches dans les ressources disponibles
- dialoguer avec une IA connectée aux données de la plateforme
- obtenir des réponses contextualisées grâce à un mécanisme de RAG
- retrouver l'historique des échanges ou recherches
- gérer son espace ou ses contenus de manière structurée

## Dimension IA attendue (une ou plusieurs)

Q/R sur base documentaire ; résumé automatique ; reformulation intelligente ; suggestion de ressources pertinentes ; aide à la rédaction ; extraction d'informations utiles ; assistant métier alimenté par les données de l'application.

## Dimension RAG et base vectorielle (tout ou partie)

Ingestion de contenus ; structuration ou découpage ; vectorisation et indexation ; recherche sémantique ; injection de contexte dans le prompt ; génération d'une réponse contextualisée.

## Critères d'évaluation

Compréhension du besoin métier ; cohérence du produit ; pertinence de la stack ; qualité de la démarche Vibe Coding ; capacité à utiliser l'IA pour produire, corriger, améliorer ; intégration réelle d'une fonctionnalité IA utile ; logique RAG et base vectorielle ; qualité de l'UX ; crédibilité globale du MVP.
